# Official Sources to Verify

Use these as starting points for Phase 0. Confirm each page is current and directly supports the decision before recording a compatibility claim.

- AMD ROCm documentation: https://rocm.docs.amd.com/
- AMD ROCm release notes: https://rocm.docs.amd.com/en/latest/release/release.html
- AMD Linux drivers: https://www.amd.com/en/support/download/linux-drivers.html
- Ubuntu releases: https://releases.ubuntu.com/
- Ubuntu help: https://help.ubuntu.com/
- PyTorch local installation guide: https://pytorch.org/get-started/locally/
- Tailscale Linux installation: https://tailscale.com/kb/1031/install-linux/
- Tailscale device approval: https://tailscale.com/kb/1099/device-approval/
- Vulkan: https://vulkan.org/
- Mesa documentation: https://docs.mesa3d.org/
- OBS Linux installation: https://obsproject.com/kb/linux-installation
- Linux V4L2 API documentation: https://www.kernel.org/doc/html/latest/userspace-api/media/v4l/v4l2.html
- Rust toolchain: https://www.rust-lang.org/tools/install

A general landing page is not proof that a specific hardware/software combination is supported. Link the exact compatibility page or release note used in the decision log.

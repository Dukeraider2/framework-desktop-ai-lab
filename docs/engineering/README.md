This directory defines the operating rules for the AI engineering and creative production organization. These are standards and proposed workflows, not evidence that agents or integrations have already been installed or validated.

## Authority and change control

GitHub is the primary collaboration and audit platform. Changes to these standards must be proposed through a branch and pull request, reviewed, and approved by the repository owner. Do not silently change an approved standard.

## Status

The organization, roles, and workflows are architectural decisions. Specific agent products, model assignments, numerical resource budgets, and deployment details remain subject to evaluation and verification.

# Project Knowledge

Each project receives a dedicated directory containing durable project-specific knowledge.

Suggested contents:
- README.md — purpose, scope, current status, and navigation.
- requirements/ — specifications and acceptance criteria.
- architecture/ — diagrams, interfaces, data flows, and design decisions.
- integrations/ — links to hardware pages and integration procedures.
- references/ — project-specific reference package and source index.
- implementation/ — important implementation notes.
- testing/ — test plans, results, benchmarks, and regression history.
- operations/ — deployment, monitoring, backup, and rollback.
- decisions/ — dated architecture decision records.

Link to shared equipment pages rather than copying hardware facts into every project. Pin important references to versions or commits where practical. Keep proposed, tested, and production states distinct.

# Agent Operational Memory

This area is for durable, non-secret operational notes that help agents coordinate work. It is not a replacement for engineering specifications, project documentation, verified equipment pages, or Git history.

Store only information useful beyond a single task, identify its owner/scope and review date, and link it to the relevant project or equipment record. Expire or review stale notes. Never store credentials, tokens, private keys, personal secrets, or sensitive network identifiers.

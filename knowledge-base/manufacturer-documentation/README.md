# Manufacturer Documentation Library

Use this area to index official manuals, datasheets, firmware release notes, compatibility matrices, API references, and service documentation.

Organize by manufacturer and product family. Each record should include manufacturer and product/model applicability, document title and type, revision/publication date or firmware version, official source, retrieval date, hardware revisions and software versions covered, relevant sections or claims used, redistribution/license status, and verification status.

Prefer official manufacturer sources. Do not commit copyrighted manuals or restricted documentation unless redistribution is permitted. When in doubt, store metadata and an official link rather than a copy. Mark superseded revisions and preserve a link to the replacement.

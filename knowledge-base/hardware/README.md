# Hardware and Equipment Index

Create one directory and one primary page for each physical device or significant component in the lab. Organize by category, then manufacturer and model.

Suggested categories: compute, accelerators, networking, storage, power-and-cooling, peripherals, capture-and-audio, and embedded-and-iot.

Every equipment page must include an **Integration** section. Document the actual role of the equipment, connections and interfaces, dependent services, host/project links, compatibility, and validation status. Do not claim an integration is operational until it has been tested.

Use the [equipment page template](_templates/equipment-page.md) as the starting point. Record exact model and revision only when verified from labels, firmware, manufacturer records, or reliable system discovery.
